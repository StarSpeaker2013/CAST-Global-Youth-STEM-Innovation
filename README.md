## 📋 About

A modern, responsive single-page promotional site for the 2026 Summit:

- 🗓️ **West Regional**: July 11, 2026 — Irvine, CA
- 🏛️ **Global Final**: October 31, 2026 — King of Prussia, PA

Built with pure **HTML + CSS + JavaScript** — zero dependencies, zero build step.

## ✨ Features

- 🎨 Modern science-tech design with deep-blue + gold color scheme
- 📱 Fully responsive (mobile / tablet / desktop)
- 🎬 Smooth scroll animations and interactive elements
- 🔄 Tab-switchable competition tracks (STEM / Business)
- ⏱️ Visual competition timeline
- 🏆 Award showcase with CAST Youth Scholar recognition
- 💳 Pricing cards with early-bird highlight
- 📲 QR code registration display

## 🚀 Local Preview

Just open `index.html` in any modern browser:

```bash
# Windows
start index.html

# macOS
open index.html

# Linux
xdg-open index.html
```

Or serve locally:

```bash
python -m http.server 8000
# Then visit http://localhost:8000
```

## 🌍 Deploy to GitHub Pages

1. Create a new repo on GitHub (e.g. `cast-summit`)
2. Push this code:
   ```bash
   git remote add origin https://github.com/YOUR-USERNAME/cast-summit.git
   git branch -M main
   git push -u origin main
   ```
3. Go to **Settings → Pages**
4. Source: **Deploy from a branch** → Branch: **main** → Folder: **/ (root)**
5. Save. Your site will be live at `https://YOUR-USERNAME.github.io/cast-summit/`
